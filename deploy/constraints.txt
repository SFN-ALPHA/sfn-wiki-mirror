# Exact versions of everything `pip install "."` brings onto the mirror's container.
#
# Used as `pip install -c deploy/constraints.txt --only-binary=:all:
# --no-binary=http-ece ...` by install.sh and update.sh. A constraints file does not add
# packages; it fixes the version of any package pip decides to install, so these pins are the
# tested set and nothing newer arrives by accident on a later `wiki-mirror update` (the box runs
# unattended for weeks between looks, and a dependency that moved under it is the kind of failure
# nobody sees until the monthly build).
#
# `--only-binary=:all:` means pip never compiles anything on the box: a version without a wheel
# for this interpreter fails the install at once, loudly, instead of needing a compiler.
# `--no-binary=http-ece` is the one exception, deliberately: http-ece (a dependency of pywebpush,
# which the project's base dependencies carry) is pure Python and is published only as an sdist,
# so it is built locally; that needs setuptools, which pip fetches as a wheel, and no compiler.
#
# Source: the closure of the base dependencies in pyproject.toml,
# walked from the metadata of the workstation's test environment (the versions the test suite
# ran against), with environment markers evaluated for CPython 3.13 on linux x86_64, and
# cross-checked against pip's own resolution of `.` under these constraints (the same
# 64 packages, no version differing). That environment is Python 3.14 and the box is 3.13, so
# each pin was resolved against PyPI for CPython 3.13 on manylinux x86_64 with glibc up to 2.36
# (Debian 12; Debian 13 is newer): all of them have a wheel but http-ece. docs/OPERATIONS.md
# has the commands, and how to refresh this file.
#
# To refresh after a dependency change in pyproject.toml: rebuild the test environment, re-walk
# the closure, run the suite, re-check the wheels (docs/OPERATIONS.md), and commit the new file
# with the change that needed it. Do not edit a version by hand without doing the last two.
#
# The base dependencies do not include pywebpush or argon2-cffi, so the pins for them and for what only they bring in (http-ece
# and py-vapid, for one) are inert: a constraint on a package pip does not install does nothing.
# The next refresh drops them.
#
# Phase: W1 (docs/DESIGN.md section 6).
